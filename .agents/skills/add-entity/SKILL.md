# Add Entity Skill

Scaffold all layers for a new entity: migration, model, repository, handler, server wiring, tests, and HTTP client file. Follow existing codebase patterns precisely — never invent new patterns.

## Step 0: Clarify scope

Before writing any code, confirm with the user:
1. **Entity name** (singular, e.g. `Article`) — derive the plural form yourself.
2. **Fields** — name, type, nullable, whether stored as JSON array/object in a jsonb column, FK references.
3. **Enum types** — any fields with a fixed set of string values?
4. **Relationships** — any FK slices that need hydration from another repository?
5. **Owner-scoped?** — does each record have a `created_by` user FK with `ON DELETE CASCADE`?

Do not proceed until you have answers to 1–3. Fields and enums can be refined, but name and basic shape must be clear.

## Step 1: Migration

### Naming convention

```
src/database/migrations/YYYYMMDDSSSSSS_create_<plural>.up.sql
src/database/migrations/YYYYMMDDSSSSSS_create_<plural>.down.sql
```

Use today's date + a 6-digit sequence. Find the latest migration to determine the next sequence:

```bash
ls src/database/migrations/ | sort | tail -3
```

### Up migration template

```sql
CREATE TABLE <plural>
(
    id         TEXT        PRIMARY KEY,
    <fields>
    created_by TEXT        NOT NULL REFERENCES users (id) ON DELETE CASCADE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

Column type rules (Postgres — the datastore since CON-87; no SQLite):
- Simple string → `TEXT NOT NULL DEFAULT ''`
- String with fixed allowed values (enum) → `TEXT NOT NULL` (optionally `CHECK (col IN ('a','b'))`)
- `[]string` / map / struct stored as JSON → `jsonb NOT NULL DEFAULT '[]'` (object default `'{}'`)
- Integer → `INTEGER NOT NULL DEFAULT 0` (use `BIGINT` for a Go `int64`)
- Float → `DOUBLE PRECISION NOT NULL DEFAULT 0` (matches Go `float64`)
- Boolean → `BOOLEAN NOT NULL DEFAULT FALSE`
- Timestamp → `TIMESTAMPTZ` (standardise on UTC)
- Binary blob → `BYTEA`
- Auto-increment integer key → `BIGINT GENERATED BY DEFAULT AS IDENTITY` (rare — prefer Sqids TEXT ids)
- Embedding vector → `vector(<dim>)` (the pgvector extension is enabled in the baseline; add an HNSW index for ANN search — see the add-river-job sibling skills / `assets_chunks`)
- Optional FK → `TEXT REFERENCES other_table (id) ON DELETE SET NULL`
- Required FK → `TEXT NOT NULL REFERENCES other_table (id) ON DELETE CASCADE`

Tables are created in FK-dependency order (Postgres validates FK targets at `CREATE TABLE` time, unlike SQLite).

### Down migration template

```sql
DROP TABLE IF EXISTS <plural>;
```

## Step 2: Model (`src/models/<singular>.go`)

```go
package models

import (
    "time"

    "github.com/uptrace/bun"
)

type <Entity> struct {
    bun.BaseModel `bun:"table:<plural>,alias:<single_letter>" swaggerignore:"true"`

    ID        string    `bun:"id,pk"                                        json:"id"`
    // ... fields with aligned bun + json tags (use spaces for alignment)
    CreatedBy string    `bun:"created_by,notnull"                           json:"-"`
    CreatedAt time.Time `bun:"created_at,notnull,default:current_timestamp" json:"-"`
    UpdatedAt time.Time `bun:"updated_at,notnull,default:current_timestamp" json:"-"`
}
```

Rules:
- Alias = first letter of entity name (e.g. `alias:a` for Article).
- `CreatedBy`, `CreatedAt`, `UpdatedAt` are always `json:"-"` — they are not exposed in the API.
- JSON arrays/objects use a custom type from `src/models/types.go` (see Step 2a) **and** the field's bun tag gets `,type:jsonb` — e.g. `bun:"tag_ids,notnull,type:jsonb"` — so the dialect emits a `jsonb` column.
- Relationship slices that are hydrated (not persisted) use `bun:"-"`.
- Align `bun:"..."` and `json:"..."` tags with spaces for readability.

### Step 2a: Custom types (if needed)

Check `src/models/types.go` for existing types before adding new ones. Only add if the needed type does not exist.

Pattern for `[]string` stored as JSON. The `Value()` returns a JSON string and
`Scan()` accepts `[]byte`/`string` — this round-trips cleanly into a `jsonb`
column under pgx (verified in CON-87). The model field still needs `,type:jsonb`
in its bun tag (see Step 2 rules).

```go
// <TypeName> is a []string serialised as a JSON array in a jsonb column.
type <TypeName> []string

func (s <TypeName>) Value() (driver.Value, error) {
    b, err := json.Marshal(s)
    if err != nil {
        return nil, err
    }
    return string(b), nil
}

func (s *<TypeName>) Scan(src any) error {
    switch v := src.(type) {
    case string:
        return json.Unmarshal([]byte(v), s)
    case []byte:
        return json.Unmarshal(v, s)
    case nil:
        *s = <TypeName>{}
        return nil
    default:
        return fmt.Errorf("<TypeName>: unsupported type %T", src)
    }
}
```

## Step 3: Repository (`src/repository/<plural>.go`)

### Interface

```go
package repository

import (
    "context"

    "github.com/ogen-app/ogen/src/models"
)

// <Entity>Repository defines all persistence operations for the <Entity> domain.
type <Entity>Repository interface {
    List(ctx context.Context) ([]models.<Entity>, error)
    Create(ctx context.Context, e *models.<Entity>) error
    GetByID(ctx context.Context, id string) (*models.<Entity>, error)
    Update(ctx context.Context, e *models.<Entity>) error
    Delete(ctx context.Context, id string) (bool, error)
}
```

Add `GetByIDs(ctx context.Context, ids []string) (map[string]models.<Entity>, error)` only if other entities will hydrate this one.

### Implementation

```go
type <entity>Repository struct {
    db *bun.DB
    // add dependent repos only if hydration is needed
}

func New<Entity>Repository(db *bun.DB) <Entity>Repository {
    return &<entity>Repository{db: db}
}

func (r *<entity>Repository) List(ctx context.Context) ([]models.<Entity>, error) {
    var items []models.<Entity>
    if err := r.db.NewSelect().Model(&items).OrderExpr("created_at ASC").Scan(ctx); err != nil {
        return nil, err
    }
    return items, nil
}

func (r *<entity>Repository) Create(ctx context.Context, e *models.<Entity>) error {
    _, err := r.db.NewInsert().Model(e).Exec(ctx)
    return err
}

func (r *<entity>Repository) GetByID(ctx context.Context, id string) (*models.<Entity>, error) {
    item := new(models.<Entity>)
    err := r.db.NewSelect().Model(item).Where("<alias>.id = ?", id).Scan(ctx)
    if err != nil {
        if errors.Is(err, sql.ErrNoRows) {
            return nil, sql.ErrNoRows
        }
        return nil, err
    }
    return item, nil
}

func (r *<entity>Repository) Update(ctx context.Context, e *models.<Entity>) error {
    _, err := r.db.NewUpdate().Model(e).WherePK().Exec(ctx)
    return err
}

func (r *<entity>Repository) Delete(ctx context.Context, id string) (bool, error) {
    res, err := r.db.NewDelete().Model((*models.<Entity>)(nil)).Where("id = ?", id).Exec(ctx)
    if err != nil {
        return false, err
    }
    n, _ := res.RowsAffected()
    return n > 0, nil
}
```

If hydration of related entities is needed, call `HydrateTags` / `HydratePlatforms` (or the appropriate generic helper in `src/repository/hydrate.go`) after the `List` query, and initialise empty slices for each item first.

## Step 4: Handler (`src/handlers/<plural>.go`)

```go
package handlers

import (
    "database/sql"
    "errors"
    "time"

    "github.com/gofiber/fiber/v2"

    "github.com/ogen-app/ogen/src/models"
    "github.com/ogen-app/ogen/src/repository"
)

type <Entity>Handler struct {
    repo repository.<Entity>Repository
    auth fiber.Handler
}

func New<Entity>Handler(repo repository.<Entity>Repository, auth fiber.Handler) *<Entity>Handler {
    return &<Entity>Handler{repo: repo, auth: auth}
}

func (h *<Entity>Handler) Register(app *fiber.App) {
    g := app.Group("/api/<plural>")
    g.Get("/", h.auth, h.List)
    g.Post("/", h.auth, h.Create)
    g.Get("/:id", h.auth, h.Get)
    g.Put("/:id", h.auth, h.Update)
    g.Delete("/:id", h.auth, h.Delete)
}

type <entity>Request struct {
    // Only mutable fields — never ID, CreatedBy, CreatedAt, UpdatedAt
    Name string `json:"name" validate:"required"`
    // add other fields ...
}
```

### Handler methods

**List**
```go
// List godoc
// @Summary      List <plural>
// @Description  Returns all <plural> ordered by creation date.
// @Tags         <plural>
// @Produce      json
// @Security     CookieAuth
// @Success      200  {array}   models.<Entity>
// @Failure      401  {object}  map[string]string
// @Router       /api/<plural> [get]
func (h *<Entity>Handler) List(c *fiber.Ctx) error {
    items, err := h.repo.List(c.Context())
    if err != nil {
        return err
    }
    return c.JSON(items)
}
```

**Create**
```go
// Create godoc
// @Summary      Create <singular>
// @Description  Creates a new <singular>. The created_by field is set from the authenticated session.
// @Tags         <plural>
// @Accept       json
// @Produce      json
// @Security     CookieAuth
// @Param        body  body      <entity>Request  true  "<Entity> payload"
// @Success      201   {object}  models.<Entity>
// @Failure      400   {object}  map[string]string
// @Failure      401   {object}  map[string]string
// @Router       /api/<plural> [post]
func (h *<Entity>Handler) Create(c *fiber.Ctx) error {
    var req <entity>Request
    if err := c.BodyParser(&req); err != nil {
        return fiber.NewError(fiber.StatusBadRequest, err.Error())
    }
    if err := validate.Struct(&req); err != nil {
        return fiber.NewError(fiber.StatusBadRequest, validationError(err).Error())
    }
    // Validate enum fields here (not via struct tags):
    // if !valid<Field>s[req.<Field>] {
    //     return fiber.NewError(fiber.StatusBadRequest, "invalid <field>")
    // }

    session := c.Locals("session").(*models.Session)

    id, err := models.NewID()
    if err != nil {
        return err
    }

    item := &models.<Entity>{
        ID:        id,
        Name:      req.Name,
        CreatedBy: session.UserID,
    }
    if err := h.repo.Create(c.Context(), item); err != nil {
        return err
    }
    return c.Status(fiber.StatusCreated).JSON(item)
}
```

**Get**
```go
// Get godoc
// @Summary      Get <singular>
// @Description  Returns a single <singular> by Sqid.
// @Tags         <plural>
// @Produce      json
// @Security     CookieAuth
// @Param        id   path      string  true  "<Entity> Sqid"
// @Success      200  {object}  models.<Entity>
// @Failure      401  {object}  map[string]string
// @Failure      404  {object}  map[string]string
// @Router       /api/<plural>/{id} [get]
func (h *<Entity>Handler) Get(c *fiber.Ctx) error {
    item, err := h.repo.GetByID(c.Context(), c.Params("id"))
    if err != nil {
        if errors.Is(err, sql.ErrNoRows) {
            return fiber.NewError(fiber.StatusNotFound, "<singular> not found")
        }
        return err
    }
    return c.JSON(item)
}
```

**Update**
```go
// Update godoc
// @Summary      Update <singular>
// @Description  Updates an existing <singular>.
// @Tags         <plural>
// @Accept       json
// @Produce      json
// @Security     CookieAuth
// @Param        id    path      string          true  "<Entity> Sqid"
// @Param        body  body      <entity>Request true  "<Entity> payload"
// @Success      200   {object}  models.<Entity>
// @Failure      400   {object}  map[string]string
// @Failure      401   {object}  map[string]string
// @Failure      404   {object}  map[string]string
// @Router       /api/<plural>/{id} [put]
func (h *<Entity>Handler) Update(c *fiber.Ctx) error {
    var req <entity>Request
    if err := c.BodyParser(&req); err != nil {
        return fiber.NewError(fiber.StatusBadRequest, err.Error())
    }
    if err := validate.Struct(&req); err != nil {
        return fiber.NewError(fiber.StatusBadRequest, validationError(err).Error())
    }

    item, err := h.repo.GetByID(c.Context(), c.Params("id"))
    if err != nil {
        if errors.Is(err, sql.ErrNoRows) {
            return fiber.NewError(fiber.StatusNotFound, "<singular> not found")
        }
        return err
    }

    item.Name = req.Name
    item.UpdatedAt = time.Now().UTC()

    if err := h.repo.Update(c.Context(), item); err != nil {
        return err
    }
    return c.JSON(item)
}
```

**Delete**
```go
// Delete godoc
// @Summary      Delete <singular>
// @Description  Deletes a <singular> by Sqid.
// @Tags         <plural>
// @Security     CookieAuth
// @Param        id   path  string  true  "<Entity> Sqid"
// @Success      204
// @Failure      401  {object}  map[string]string
// @Failure      404  {object}  map[string]string
// @Router       /api/<plural>/{id} [delete]
func (h *<Entity>Handler) Delete(c *fiber.Ctx) error {
    deleted, err := h.repo.Delete(c.Context(), c.Params("id"))
    if err != nil {
        return err
    }
    if !deleted {
        return fiber.NewError(fiber.StatusNotFound, "<singular> not found")
    }
    return c.SendStatus(fiber.StatusNoContent)
}
```

## Step 6: Tests (`src/handlers/<plural>_test.go`)

Use **Ginkgo v2 + Gomega**. Follow the exact pattern in `src/handlers/tags_test.go` — it is the canonical minimal example.

Key rules:
- `BeforeAll`: `db = mustOpenTestDBWithMigrations()` — a fresh, fully-migrated **Postgres** database, one per suite block (backed by `src/pgtest`; each call provisions its own database, so suites stay isolated). The suite needs a running Postgres, which `make test` provisions automatically.
- `BeforeEach`: create a fresh Fiber app, wire all required repositories and handlers, create a test user via `POST /api/users`, and log in to get `authCookie`.
- `AfterEach`: delete all rows from every table touched by the tests (in FK-safe order, children first). Always delete `sessions` and `users` last.
- Use a `create<Entity>` helper function to avoid repetition in tests.
- Test every route for: unauthenticated → 401, happy path, invalid input → 400, not found → 404 (for Get/Update/Delete).
- Decode response bodies into `models.<Entity>` and assert field values — don't just check the status code.

### Test file structure

```go
package handlers_test

import (
    "bytes"
    "context"
    "encoding/json"
    "net/http"
    "net/http/httptest"

    "github.com/gofiber/fiber/v2"
    . "github.com/onsi/ginkgo/v2"
    . "github.com/onsi/gomega"
    "github.com/uptrace/bun"

    "github.com/ogen-app/ogen/src/handlers"
    "github.com/ogen-app/ogen/src/models"
    "github.com/ogen-app/ogen/src/repository"
)

var _ = Describe("<Entity>Handler", Ordered, func() {
    var (
        app        *fiber.App
        db         *bun.DB
        authCookie *http.Cookie
    )

    BeforeAll(func() {
        db = mustOpenTestDBWithMigrations()
    })

    BeforeEach(func() {
        app = fiber.New(fiber.Config{
            ErrorHandler: func(c *fiber.Ctx, err error) error {
                code := fiber.StatusInternalServerError
                if e, ok := err.(*fiber.Error); ok {
                    code = e.Code
                }
                return c.Status(code).JSON(fiber.Map{"error": err.Error()})
            },
        })
        userRepo := repository.NewUserRepository(db)
        sessionRepo := repository.NewSessionRepository(db)
        settingRepo := repository.NewSettingRepository(db)
        <plural>Repo := repository.New<Entity>Repository(db)
        auth := handlers.RequireAuth(sessionRepo, testCookieName)
        handlers.NewUsersHandler(userRepo, settingRepo, auth).Register(app)
        handlers.NewSessionsHandler(userRepo, sessionRepo, testCookieName, false).Register(app)
        handlers.New<Entity>Handler(<plural>Repo, auth).Register(app)

        body, _ := json.Marshal(fiber.Map{"name": "Admin", "email": "admin@example.com", "password": "admin-password"})
        req := httptest.NewRequest("POST", "/api/users", bytes.NewReader(body))
        req.Header.Set("Content-Type", "application/json")
        resp, err := app.Test(req)
        Expect(err).NotTo(HaveOccurred())
        Expect(resp.StatusCode).To(Equal(fiber.StatusCreated))

        loginBody, _ := json.Marshal(fiber.Map{"email": "admin@example.com", "password": "admin-password"})
        loginReq := httptest.NewRequest("POST", "/api/sessions", bytes.NewReader(loginBody))
        loginReq.Header.Set("Content-Type", "application/json")
        loginResp, err := app.Test(loginReq)
        Expect(err).NotTo(HaveOccurred())
        Expect(loginResp.StatusCode).To(Equal(fiber.StatusCreated))
        cookies := loginResp.Cookies()
        Expect(cookies).To(HaveLen(1))
        authCookie = cookies[0]
    })

    AfterEach(func() {
        _, err := db.NewDelete().TableExpr("<plural>").Where("1 = 1").Exec(context.Background())
        Expect(err).NotTo(HaveOccurred())
        _, err = db.NewDelete().TableExpr("sessions").Where("1 = 1").Exec(context.Background())
        Expect(err).NotTo(HaveOccurred())
        _, err = db.NewDelete().TableExpr("users").Where("1 = 1").Exec(context.Background())
        Expect(err).NotTo(HaveOccurred())
    })

    create<Entity> := func(name string /*, other required fields */) models.<Entity> {
        body, _ := json.Marshal(fiber.Map{"name": name})
        req := httptest.NewRequest("POST", "/api/<plural>", bytes.NewReader(body))
        req.Header.Set("Content-Type", "application/json")
        req.AddCookie(authCookie)
        resp, err := app.Test(req)
        Expect(err).NotTo(HaveOccurred())
        Expect(resp.StatusCode).To(Equal(fiber.StatusCreated))
        var item models.<Entity>
        Expect(json.NewDecoder(resp.Body).Decode(&item)).To(Succeed())
        return item
    }

    // ── List ──────────────────────────────────────────────────────────────────

    Describe("GET /api/<plural>", func() {
        Context("when not authenticated", func() {
            It("returns 401", func() {
                req := httptest.NewRequest("GET", "/api/<plural>", nil)
                resp, err := app.Test(req)
                Expect(err).NotTo(HaveOccurred())
                Expect(resp.StatusCode).To(Equal(401))
            })
        })

        Context("when authenticated", func() {
            It("returns an empty list when no <plural> exist", func() {
                req := httptest.NewRequest("GET", "/api/<plural>", nil)
                req.AddCookie(authCookie)
                resp, err := app.Test(req)
                Expect(err).NotTo(HaveOccurred())
                Expect(resp.StatusCode).To(Equal(200))
                var items []models.<Entity>
                Expect(json.NewDecoder(resp.Body).Decode(&items)).To(Succeed())
                Expect(items).To(BeEmpty())
            })

            It("returns all <plural>", func() {
                create<Entity>("First")
                create<Entity>("Second")
                req := httptest.NewRequest("GET", "/api/<plural>", nil)
                req.AddCookie(authCookie)
                resp, err := app.Test(req)
                Expect(err).NotTo(HaveOccurred())
                Expect(resp.StatusCode).To(Equal(200))
                var items []models.<Entity>
                Expect(json.NewDecoder(resp.Body).Decode(&items)).To(Succeed())
                Expect(items).To(HaveLen(2))
            })
        })
    })

    // ── Create ────────────────────────────────────────────────────────────────

    Describe("POST /api/<plural>", func() {
        Context("when not authenticated", func() {
            It("returns 401", func() {
                body, _ := json.Marshal(fiber.Map{"name": "Test"})
                req := httptest.NewRequest("POST", "/api/<plural>", bytes.NewReader(body))
                req.Header.Set("Content-Type", "application/json")
                resp, err := app.Test(req)
                Expect(err).NotTo(HaveOccurred())
                Expect(resp.StatusCode).To(Equal(401))
            })
        })

        Context("when authenticated", func() {
            It("creates a <singular> and returns 201", func() {
                body, _ := json.Marshal(fiber.Map{"name": "My <Entity>"})
                req := httptest.NewRequest("POST", "/api/<plural>", bytes.NewReader(body))
                req.Header.Set("Content-Type", "application/json")
                req.AddCookie(authCookie)
                resp, err := app.Test(req)
                Expect(err).NotTo(HaveOccurred())
                Expect(resp.StatusCode).To(Equal(201))
                var item models.<Entity>
                Expect(json.NewDecoder(resp.Body).Decode(&item)).To(Succeed())
                Expect(item.ID).NotTo(BeEmpty())
                Expect(item.Name).To(Equal("My <Entity>"))
            })

            It("returns 400 when name is missing", func() {
                body, _ := json.Marshal(fiber.Map{})
                req := httptest.NewRequest("POST", "/api/<plural>", bytes.NewReader(body))
                req.Header.Set("Content-Type", "application/json")
                req.AddCookie(authCookie)
                resp, err := app.Test(req)
                Expect(err).NotTo(HaveOccurred())
                Expect(resp.StatusCode).To(Equal(400))
            })
        })
    })

    // ── Get ───────────────────────────────────────────────────────────────────

    Describe("GET /api/<plural>/:id", func() {
        Context("when not authenticated", func() {
            It("returns 401", func() {
                req := httptest.NewRequest("GET", "/api/<plural>/someid", nil)
                resp, err := app.Test(req)
                Expect(err).NotTo(HaveOccurred())
                Expect(resp.StatusCode).To(Equal(401))
            })
        })

        Context("when authenticated", func() {
            It("returns the <singular>", func() {
                item := create<Entity>("My Item")
                req := httptest.NewRequest("GET", "/api/<plural>/"+item.ID, nil)
                req.AddCookie(authCookie)
                resp, err := app.Test(req)
                Expect(err).NotTo(HaveOccurred())
                Expect(resp.StatusCode).To(Equal(200))
                var got models.<Entity>
                Expect(json.NewDecoder(resp.Body).Decode(&got)).To(Succeed())
                Expect(got.ID).To(Equal(item.ID))
                Expect(got.Name).To(Equal("My Item"))
            })

            It("returns 404 for an unknown id", func() {
                req := httptest.NewRequest("GET", "/api/<plural>/nonexistent", nil)
                req.AddCookie(authCookie)
                resp, err := app.Test(req)
                Expect(err).NotTo(HaveOccurred())
                Expect(resp.StatusCode).To(Equal(404))
            })
        })
    })

    // ── Update ────────────────────────────────────────────────────────────────

    Describe("PUT /api/<plural>/:id", func() {
        Context("when not authenticated", func() {
            It("returns 401", func() {
                body, _ := json.Marshal(fiber.Map{"name": "Updated"})
                req := httptest.NewRequest("PUT", "/api/<plural>/someid", bytes.NewReader(body))
                req.Header.Set("Content-Type", "application/json")
                resp, err := app.Test(req)
                Expect(err).NotTo(HaveOccurred())
                Expect(resp.StatusCode).To(Equal(401))
            })
        })

        Context("when authenticated", func() {
            It("updates the <singular> and returns the updated resource", func() {
                item := create<Entity>("Original")
                body, _ := json.Marshal(fiber.Map{"name": "Updated"})
                req := httptest.NewRequest("PUT", "/api/<plural>/"+item.ID, bytes.NewReader(body))
                req.Header.Set("Content-Type", "application/json")
                req.AddCookie(authCookie)
```
